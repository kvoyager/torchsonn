# Modules

`SONNModule` is the base of the model, its layers and its neurons.
`SigmaSquashNorm` is the squash of the orthogonal families (see
[Orthogonal polynomials](../../concepts/neurons/orthogonal.md#the-squash)),
and `SoftBinner` the default multi-class head (see
[Classification](../../concepts/classification.md#the-soft-binner)).
